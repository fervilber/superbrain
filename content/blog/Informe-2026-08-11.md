# Informe Técnico: Configuración de Canales y Bots de Telegram en Hermes Agent

## Contexto e Introducción
La integración de Hermes Agent con plataformas de mensajería instantánea es uno de sus pilares más potentes para permitir una interacción remota "manos libres" y asíncrona. De entre todas las opciones, **Telegram** destaca por ser la pasarela gratuita más sencilla de configurar, robusta y con soporte nativo para características avanzadas como los hilos de conversación (topics) y notas de voz (Audio/TTS).

Este informe técnico recopila y sintetiza los pasos óptimos y de mejores prácticas para configurar tu propio bot de Telegram y conectarlo de manera estable a tu servidor Hermes Agent.

---

## 1. Creación del Bot de Telegram (BotFather)
El primer paso requiere interactuar con el bot oficial de administración de Telegram, **BotFather**:
1. Abre Telegram y busca `@BotFather`.
2. Inicia una conversación y envía el comando `/newbot`.
3. Sigue las instrucciones para asignarle un **nombre de visualización** y un **nombre de usuario** (el cual debe terminar obligatoriamente en `bot`, por ejemplo, `MiServidorHermesBot`).
4. Al finalizar, BotFather te proporcionará un **Token de Acceso HTTP API** único (una cadena de texto larga con números y letras). **Guarda este token de forma segura; es la llave de tu servidor.**

---

## 2. Configuración del Entorno en Hermes
Existen dos métodos para enlazar este token con tu instancia local de Hermes Agent.

### Método A: Configuración Interactiva (Recomendado)
Desde la consola de tu VPS, ejecuta el asistente de configuración interactivo:
```bash
hermes gateway setup
```
Este comando abrirá un menú interactivo que te guiará paso a paso:
1. Selecciona **Telegram** mediante las flechas del teclado.
2. Pega el Token HTTP API cuando te lo solicite.
3. Te pedirá tu **User ID** (puedes obtenerlo enviando un mensaje a bots como `@userinfobot` en Telegram). Esto es crucial para que solo tú tengas acceso de administración al bot y evitar que terceros controlen tu servidor.

### Método B: Configuración Manual (Archivo .env)
Si prefieres saltarte el asistente gráfico, puedes añadir estas variables directamente al archivo de configuración de variables de entorno de tu perfil de Hermes:
```bash
# Añadir al final de ~/.hermes/.env
TELEGRAM_BOT_TOKEN="TU_TOKEN_DE_BOT_AQUI"
TELEGRAM_ALLOWED_USERS="TU_ID_DE_USUARIO_AQUI"
```

---

## 3. Configuración del Chat y Modo Foro (Hilos/Topics)
Un pitfall técnico muy común en los despliegues de Hermes es el manejo de los hilos de conversación. Hermes utiliza los hilos de Telegram (Forum Topics) para separar diferentes contextos de tareas, cron jobs y logs para no saturar una única ventana de chat.

Para activar esta función obligatoria:
1. Crea un **Grupo de Telegram** privado.
2. Añade a tu bot de Hermes como administrador del grupo.
3. Ve a la información del grupo, entra en ajustes y activa la opción **"Habilitar temas" (Enable Topics)** o "Modo Foro".
*Nota: Si no activas los temas en el grupo, Hermes arrojará el error `The chat is not a forum` en el log de inicio y omitirá la creación de hilos automáticos, haciendo que las entregas de tareas programadas fallen.*

---

## 4. Inicialización y Verificación
Una vez guardada la configuración, arranca o reinicia el gateway de Hermes para activar el canal:
```bash
hermes gateway start
```
Para comprobar que el túnel de mensajería está activo, abre el chat del bot en tu Telegram y envía el comando `/start`. Si todo está correcto, el bot te responderá saludándote y confirmando que está conectado a tu VPS y listo para recibir instrucciones.
