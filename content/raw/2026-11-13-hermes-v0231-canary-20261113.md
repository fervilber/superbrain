> # Hermes Agent v0.23.1 — **Release Date:** November 9, 2026

> Patch release. This tag rolls up the ~618 PRs merged since v0.23.0 into a stable release for the GitHub release (CLI and installers), the Microsoft Store app, Docker and Hermes Cloud. Full curated notes for this window ship with v0.24.0.
> What this patch ships for plugin users: since the plugin catalog's site deploy on November 9, the published `plugin-catalog.json` was larger than the 2 MiB cap clients accept, so every install silently fell back to the catalog it shipped with. `hermes plugins install` could not find plugins added since your last update, installed the pin your release shipped instead of the current one, and missed newer `removed` entries. This release raises the cap to 16 MiB, so the live catalog is used again (#151860, fixes #151856, thanks @100yenadmin). Installs that stay on v0.23.0 or older keep falling back until they update.

## Plugin oficial de seguridad (hermes-security)

> Nous Research has introduced an official Security plugin for Hermes Agent, expanding the capabilities of its artificial intelligence platform with automated code security reviews. The new plugin, called hermes-security, is designed to help developers identify vulnerabilities, investigate potential attack paths and improve software security through AI-powered analysis.

> The plugin approaches security reviews by first building a threat model of the repository. It identifies which parts of the application an attacker could potentially access and determines which inputs the software trusts. [...] Hermes divides the codebase into smaller sections and distributes the review among multiple parallel AI subagents. These agents examine different portions of the repository, investigate suspicious code and evaluate possible vulnerabilities. The system subsequently checks candidate findings against the actual code and traces whether an attacker could realistically exploit them.

> When enabled, Hermes can write small reproductions of suspected vulnerabilities and execute them in a temporary copy of the repository. [...] However, developers should understand that this temporary environment is not a security sandbox, since repository code still executes with the user's privileges. The plugin produces detailed reports containing supporting evidence, rejected findings and information about the code examined. Reports can be exported in Markdown, JSON, CSV and SARIF formats.

> Installation requires Hermes version 0.21.5 or later and Python 3.11 or later. [...] Source code reviewed by the agent is transmitted to the configured model provider, while dependency information may be shared with external vulnerability databases.

> Nous Research's open-source Hermes Agent is trending after a long, independent review by @Da7_Tech praised its model-neutral design, persistent memory and about 165 built-in skills, and listed real weak spots. Hermes Agent is MIT-licensed and free.
