## AWS: Bedrock AgentCore and Strands updates make production agents more reliable and cheaper

> **What changed:** AWS published a recap of October updates showing Amazon Bedrock AgentCore added a stable AgentCore CLI (v1.0) and an AgentCore Gateway that supports model fallback and connecting existing Step Functions workflows as callable tools for agents. The post also announced Strands Bidi Agents (speech-to-speech) is generally available and Strands Box is in developer preview, plus new cost and billing visibility for Bedrock workloads.
>
> **Why it matters:** Platform and ops teams can now route agent requests across multiple models automatically if a primary model is throttled, call existing business workflows (Step Functions) from agents, and see which models are driving spend—so you avoid building brittle per-provider glue and get clearer cost signals.
>
> **Try/watch:** If you run or plan an agent in production, test AgentCore Gateway with a fallback chain (primary → secondary model) and swap one non-critical workflow to run through a Step Functions tool to validate identity, auditing, and JSON-structured outputs before wider rollout.

## Google Labs: Tabletop — espacios grupales compartidos que generan herramientas de planificación colaborativa

> **What changed:** Google Labs launched Tabletop, a waitlist experiment that gives a shared space where people drop links/files and ask @tabletop to generate editable planning tools (itineraries, polls, expense splitters, brackets) that multiple users can edit in real time. The experiment is rolling out to U.S. adults via a waitlist.
>
> **Why it matters:** For product and ops teams building lightweight group workflows, Tabletop is a practical example of small, agent-built apps that nontechnical users can instantiate and modify together—meaning teams can prototype agent-driven shared tooling without building full apps or integrations.
>
> **Try/watch:** Sign up for the waitlist, experiment with a shared planning space for a real team task, and observe how Tabletop's generated schema and interactive components map to your existing data model.
