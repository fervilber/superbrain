# Databricks opens Genie ZeroOps to public beta (autonomous pipeline agent)

AI Agent Store (Daily AI Agent News) — 19 de noviembre de 2026

**What changed:** Databricks announced **Genie ZeroOps** in public beta on November 19, 2026; the agent continuously monitors jobs and tables, diagnoses failures using **Unity Catalog metadata and lineage**, runs **dry-run tests**, and proposes fixes as **PRs** while requiring **human approval before changing production**.

**Why it matters:** Data teams can reduce hours spent triaging broken pipelines because ZeroOps ships with direct access to workspace lineage, run history and repository integration, letting it surface prioritized root causes and a one-click PR to fix common issues. The product is built to run **inside your Databricks security perimeter** and **respects workspace permissions**.

**Try/watch:** Enable ZeroOps in a sandbox workspace, test its detection-to-PR flow on noncritical pipelines, and add custom instructions to tune noisy alerts; watch how it handles complex cross-team fixes, and guard any agent-run attempts to modify production without explicit approval.
