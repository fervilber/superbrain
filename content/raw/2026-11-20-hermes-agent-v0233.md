# Hermes Agent v0.23.3

Nous Research — **Release Date: November 19, 2026**

> Patch release. This tag rolls up the **~370 PRs merged since v0.23.2** into a stable release for the GitHub release (CLI and installers), the Microsoft Store app, Docker and Hermes Cloud. Full curated notes for this window ship with v0.24.0.

## About this release

Measured at commit `caafe5389ae`, the window since v0.23.2 contains **1,657 non-merge commits** across **3,948 changed files** (+222,379 / −96,154), **370 merged PRs** and **60 closed issues**.

## Contenido destacado de la release

Hermes Agent releases v0.23.3, a patch update for CLI, installers, Microsoft Store, Docker and Hermes Cloud. The release includes:

- **prompt-cache lifecycle improvements**,
- **smarter chat compaction and pruning**,
- **simpler first-run setup**,
- **new model options**, and
- other **platform and security updates**.

## Actualización

- **Microsoft Store app**: se actualiza vía la Store.
- **Desktop app** instalada desde el instalador (.exe / .dmg): sin cambios en esta release; se actualiza con el siguiente _bundled release_.
- **CLI**: `hermes update`, o re-ejecutar el instalador.
- **Docker / Hermes Cloud**: `nousresearch/hermes-agent:stable` (o `:latest`).
