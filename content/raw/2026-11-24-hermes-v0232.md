# Hermes Agent — releases (noviembre de 2026)

## Hermes Agent v0.23.2 (stable)

Release Date: November 16, 2026. Commit `ae2a81c`.

Patch release. This tag rolls up the ~1,989 PRs merged since v0.23.1 into a stable release for the GitHub release (CLI and installers), the Microsoft Store app, Docker and Hermes Cloud. Full curated notes for this window ship with v0.24.0.

Measured at commit `ae2a81ccc00`, the window since v0.23.1 contains 7,918 non-merge commits across 5,211 changed files (+239,733 / −22,788), 1,989 merged PRs and 940 closed issues.

Full curated release notes for this window ship with v0.24.0, which will document everything from v0.23.0 onward — highlights, feature areas, and complete contributor credits. Nothing in this window is skipped.

### Novedades destacadas del ventana (según recopilaciones de la comunidad)

- Durable subagents that survive a gateway restart or crash and can be continued on their own conversation.
- `hermes fallback check`, to confirm your fallback chain is ready.
- `hermes update --force`, to stop gateways at once instead of draining.
- Per-job cron options such as `wrap_response` and a fresh thread per run.
- New plugin APIs: `ctx.fork_session`, `ctx.redact_text()`, `ctx.register_idle_task`.
- Compatibility shims so updates work across module moves.
- A slimmer macOS bundle that installs Chromium on first use.
- Large batch of new plugin-catalog entries.

### Fixes

- Desktop no longer loses or scrambles what you type while it starts and resumes your last chat.
- The Stop button no longer stays up after a reply that streamed beside a todo or memory call.
- After a reconnect mid-reply, Desktop shows the reply once and in full, attachments included.
