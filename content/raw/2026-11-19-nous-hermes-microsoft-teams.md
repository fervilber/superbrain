# Nous Research partners with Microsoft to bring Hermes Agent to the enterprise

November 18, 2026 — Press release (Nous Research).

- Hermes Agent, from M12, Microsoft's Venture Fund portfolio company Nous Research, now works inside the Microsoft tools enterprises already use: Hermes Desktop in the Microsoft Store, Microsoft Teams, and agent execution on Microsoft Azure Container Apps Sandboxes.
- Collective Wisdom lets employees turn a great way of solving a problem into a skill their teammates can use, so the best way of working becomes available to everyone.
- The number one app on OpenRouter's global ranking is now available for enterprises in Microsoft Teams, the Microsoft Store and on Azure.
- Nous Research will present at Microsoft Ignite session BRK448, "Run secure agent loops in production with isolated sandboxes at scale."

NEW YORK, Nov. 18, 2026. Nous Research, an M12 portfolio company and the team behind Hermes Agent, today announced that Hermes Agent is available in native Microsoft services for the enterprise. Hermes Agent currently ranks number one among public open agents on OpenRouter, processing nearly 2 trillion tokens a day. With Hermes Enterprise, every employee gets a managed, self-improving agent in the tools they already use, and the company gains shared intelligence that grows with every task.

## Coming to where you already work

Hermes Enterprise is designed to feel like a native part of the Microsoft workplace:

- Hermes Desktop for Windows, available in the Microsoft Store.
- Microsoft Teams, where employees can assign Hermes knowledge work, from financial analysis and drafting documents to triaging an inbox, and review the finished result in the same conversation.
- Microsoft Azure Container Apps Sandboxes, where agent workloads run in isolated microVMs that start in under a second and release compute when idle.

## Shared intelligence from everyday work

Most AI tools help one person finish one task. The judgment behind that work, the tacit knowledge of how a company actually gets things done, rarely gets shared beyond the person who has it. Hermes Agent works differently. As an employee delegates recurring work, Hermes automatically turns a successful approach into a reusable skill: a written definition paired with code that runs the stable steps the same way every time, so established workflows use less inference and become more reliable over time.

With Collective Wisdom, employees can ask Hermes which of their skills are worth sharing, then propose and publish them for their team with review. The next person who attempts the task starts from the best approach anyone on the team has found, on day one. Every employee contributes to the company's shared intelligence and benefits from it, and that intelligence remains a private asset of the organization rather than training data for an AI vendor.

## Run it in your own Azure tenant

For organizations that need to keep workloads inside their own boundary, agent execution can run in Microsoft Azure Container Apps Sandboxes inside the customer's tenant, in isolated microVMs. Session data, files and credentials stay in the customer's environment; the sandboxes start in under a second and release compute when idle, so cost tracks actual usage rather than reserved capacity.
