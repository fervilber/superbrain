Hermes Agent v0.22.2 lets users ask Hermes Desktop to find and install matching plugins or skills, and adds a built-in app tour. The features are described by community member Witcheer, who says both are already available.

Why it matters

Other changes include plugins searching common installation locations across Windows, macOS and Linux, rather than relying on one fixed folder. Two more features are planned for a later release: countdowns for repeating tasks and options to keep or set aside unfinished code when closing a coding session. Small conveniences, perhaps, but the sort that make an AI agent less of a project to configure.

Discuss: Which matters more in an agent desktop app: easier setup, or better safeguards for work in progress?
