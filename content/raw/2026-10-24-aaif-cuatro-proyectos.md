# Agentic AI Foundation Announces Four New Projects: Agent Skills, Open Responses, OpenEnv, and OpenSandbox

October 22, 2026

## Summary

- AAIF announced four new projects: Agent Skills, contributed by Anthropic; Open Responses, contributed by OpenAI; OpenEnv, contributed by Hugging Face; and OpenSandbox, contributed by Alibaba.
- AAIF has grown from three projects to 10 in its first year.
- Announced at AGNTCon + MCPCon North America, the new projects extend AAIF's portfolio across agent capabilities, model interoperability, training environments, and secure execution, all under open, vendor-neutral governance.

SAN JOSE, Calif., October 22, 2026 — AGNTCon + MCPCon North America — The Agentic AI Foundation (AAIF) today announced four new projects: Agent Skills, contributed by Anthropic; Open Responses, contributed by OpenAI; OpenEnv, contributed by Hugging Face; and OpenSandbox, contributed by Alibaba. The additions bring AAIF to 10 hosted projects in its first year, up from its three launch projects in December 2025. The new projects address four layers of the agentic stack: how agents gain new skills, how applications talk to models across providers, how agents are trained and evaluated, and where agents run safely. They join the Agent2Agent (A2A) protocol, Agent Router, agentgateway, AGENTS.md, goose, and the Model Context Protocol (MCP) as AAIF projects, all operating under AAIF's open, vendor-neutral governance.

**Agent Skills** is an open format for giving agents new capabilities and domain expertise. Skills package instructions, scripts and resources in a reusable manner that agents can load on demand, making specialized know-how portable across agent products and platforms.

We launched Agent Skills a year ago to give developers and enterprises alike an open standard to make their agents more capable. Today, we're donating Agent Skills to the AAIF to ensure that anyone building with skills can shape what's next. **Open Responses** is an open specification for building multi-provider, interoperable LLM interfaces, based on the OpenAI Responses API. It defines a shared schema, consistent streaming events and extensible tooling, so developers can describe requests and outputs once and run them across model providers with minimal translation.

**OpenEnv** is an open framework and community hub for creating RL environments that makes them interoperable, plug-and-play, easy to build, easy to share, and scalable. It does this through a simple containerized service that exposes a familiar agent interface, MCP, and the training protocol that training libraries use, Gym.

**OpenSandbox** is a general-purpose sandbox platform for AI applications. It offers multi-language SDKs, unified sandbox APIs and Docker and Kubernetes runtimes for use cases including coding agents, GUI agents, agent evaluation, AI code execution and reinforcement learning training. It includes a sandbox protocol that defines lifecycle and execution APIs, so teams can extend it with custom runtimes.
