# Google Agent Development Kit (ADK) 2.14.0 — A2A estable (7 de noviembre de 2026)

Categoría: Framework de agentes. Fuente principal: techjacksolutions.com (9-nov-2026). Fuentes secundarias: dailybyte.pk (8-nov-2026), luminvera.com (8-nov-2026), palai.media (13-nov-2026).

## Extractos verbatim

> Google shipped **google-adk 2.14.0** on **November 7, 2026**, graduating the Agent2Agent protocol, execution sandboxes, and core runtime modules from experimental to stable status.

> In total, **26 modules** covering authentication, environments, apps, the command line and caching move to stable, alongside **16 toolset integrations.**

> The release also adds an **`adk generate_agent_card`** command that builds A2A agent cards from the command line, describing what an agent can do so other agents can find and use it.

> **Stable means something specific.** It means the API contract is settled, breaking changes require a deprecation cycle, and teams can build production systems against it without expecting the ground to shift underneath them.

> Google reports **23% speed improvement and 9% lower peak memory on 30-node, 200-turn workflows**, Google internal testing, **no baseline hardware disclosed**. […] Treat as a directional signal, not a planning number.

> Per Google's release notes, 2.14.0 also adds **TeamsRunner** for deploying ADK agents directly within Microsoft Teams chats and channels, and **MultiRunConfig** for running evaluation cases concurrently.

> The A2A vs. MCP distinction is worth a sentence. **MCP (Model Context Protocol) governs model-to-tool connectivity**, how a model accesses external resources. **A2A governs agent-to-agent task delegation**, how one agent hands off work to another. They're complementary, not competing.

## Cifras de adopción (luminvera.com, 8-nov-2026)
