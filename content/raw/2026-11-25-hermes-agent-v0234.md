# Hermes Agent v0.23.4

URL: https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.4
Repository: NousResearch/hermes-agent

Published: 2026-11-24T08:17:06Z

> Patch release. This tag rolls up the ~229 PRs merged since v0.23.3 into a stable release for the GitHub release (CLI and installers), the Microsoft Store app, Docker and Hermes Cloud. Full curated notes for this window ship with v0.24.0.

## About this release

Measured at commit 8fc03744473, the window since v0.23.3 contains **1,122 non-merge commits** across **1,316 changed files** (+96,873 / −6,703), **229 merged PRs** and **281 closed issues**.

Also in the window, undocumented here on purpose: Gemini 4 Hydrogen, Neon and Carbon on Nous Portal, OpenRouter and Vertex; `hermes gateway migrate --backends` to move an old serve/dashboard backend onto the gateway (with a System page card in the dashboard); `hermes plugins config` to edit a plugin's settings from the terminal; approval cards in Desktop for a sandbox's folder and site requests; gateway clients announcing who they are so plugins can see which client sent a turn; a long run of Desktop streaming and transcript performance work; a retryable indicator for slow profile switches; `hermes dashboard password` without a TTY prompt; configurable skill index description length (`skills.index_desc_limit`); managed-scope config honored by security and URL-safety reads; and a large batch of new plugin-catalog entries.

Full curated release notes for this window ship with **v0.24.0**, which will document everything from v0.23.0 onward — highlights, feature areas, and complete contributor credits. Nothing in this window is skipped.

## Updating

- Microsoft Store app: updates through the Store.
- Desktop app installed from the installer (.exe / .dmg): no change in this release; it updates with the next bundled release.
- CLI: `hermes update`, or re-run the installer one-liner.
- Docker / Hermes Cloud: `nousresearch/hermes-agent:stable` (or `:latest`).

## Análisis de terceros (Freedom.Tech / labmemo)

URL: https://freedom.tech/posts/2026-11-24-hermes-agent-0-23-4/

At a glance: Hermes Agent 0.23.4 stabilizes 229 merged PRs including Gemini 4 model support, gateway migration tooling, plugin configuration CLI, and performance improvements across Desktop streaming and profile switching.

Análisis en japonés (labmemo, 2026-11-24): los cambios destacados son de modelos y operación. Los modelos de la familia Gemini 4 (Hydrogen, Neon, Carbon) pueden seleccionarse a través de Nous Portal, OpenRouter y Vertex. En operación se incluyen el comando de migración del gateway, la edición de la configuración de plugins desde la terminal y las tarjetas de aprobación en la app Desktop. La distribución cubre CLI (GitHub Releases e instalador), la app de Microsoft Store, Docker y Hermes Cloud; la CLI se actualiza con `hermes update`. La app Desktop instalada con instalador (.exe/.dmg) no cambia en este release y se actualizará en el siguiente release empaquetado.

Cambios de configuración y seguridad: `hermes dashboard password` funciona ya sin TTY (útil en scripts y automatización); `skills.index_desc_limit` permite fijar la longitud de la descripción que aparece en el índice de skills; y la configuración de ámbito gestionado (managed-scope) se respeta también en las lecturas de seguridad y de seguridad de URL.

Relación con versiones previas: v0.23.3 (20 nov) integró ~370 PRs (setup de CLI en una sola pregunta, ciclo de vida de la caché de prompt); v0.23.2 añadió subagentes persistentes y `hermes update --force`; v0.23.1 corrigió fallos del catálogo de plugins; v0.23.0 fue la «The Hearth Release» que consolidó la serie v0.22.

También existe un canary `canary.20261125T064800Z-v0.23.4` publicado el 25 nov (commit 2435384), con smoke tests de macOS DMG+ZIP (arm64) y Windows MSIX (arm64/x64) en estado «Passed».
