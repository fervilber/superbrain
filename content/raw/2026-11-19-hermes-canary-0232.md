# Hermes Agent canary v0.23.2+canary.20261119T064637Z (Releasebot)

Hermes Agent releases a canary update that adds Remedigenius to its plugin catalog and improves prompt caching and conversation compression. It also fixes gateway, search, terminal, and desktop issues, with native install and chat smoke tests passing for listed macOS and Windows packages.

Release Date: November 19, 2026.

## Downloads

- macOS Apple Silicon (M-series) DMG
- Windows x86 (64-bit) MSIX
- Windows ARM (arm64 / aarch64) MSIX

Packages smoke status: macOS DMG + ZIP (arm64) Passed; Windows MSIX (arm64) Passed; Windows MSIX (x64) Passed. Linux bundles are disabled; unsigned Store envelopes are not install-smoked.

- Remedigenius to the plugin catalog (a66bd08e) — @RajaRenga
