# Hermes Agent: la línea 0.22.x

## v0.22.3 (21 de octubre de 2026)

Release de parche que agrupa **~620 PRs** fusionados desde v0.22.2. Medido en el commit `5b147ab036d`: 2.911 commits no-merge, 4.206 archivos cambiados (+360.278 / −64.308), ~620 PRs y 326 issues cerrados. Cubre CLI e instalador, app de Microsoft Store, Docker y Hermes Cloud. Las notas curadas completas llegan con v0.23.0.

Cambios del ventana (lista intencionalmente no documentada en detalle):

- **Notificaciones de progreso MCP** transmitidas como progreso de herramienta en vivo.
- Diseño clásico de CLI renovado: transcripción con glifos, línea de estado bajo el compositor, cabecera de dos líneas.
- **Clientes OAuth que los plugins declaran** y Hermes inicia sesión y refresca.
- `hermes plugins update` ofrece todas las actualizaciones disponibles; botón Update para plugins instalados por git en Desktop.
- **Steering y edición de un prompt en cola** desde Desktop.
- Selector guiado de modelo y proveedor para subagentes en Desktop.
- Fila de cuenta atrás `/loop` en vivo en CLI y TUI.
- Transferencia opt-in de temas en DMs de Telegram.
- Hook de plugin `post_compaction`.
- Catálogo de capacidades.
- Build de Microsoft Store publicada automáticamente al publicar un release.
- Auto-prune de sesiones vuelve a ser opt-in, con aviso único cuando se acaba el disco.
- Nemotron 3.5 Bolt y borradores DFlash de una ranura en el runtime local.

## v0.22.4 (21 de octubre, 13 PRs)

Desktop deja de mostrar "suggestion pills" sobre el compositor (aparecían sin motivo, empujando a configurar servidores MCP) y se eliminan los helpers que solo ellas usaban. Plugins que no instalan nada se saltan el paso de consentimiento de dependencias. Dashboard: WhatsApp se puede reemparejar tras cerrar sesión. El chip de modo de aprobación sigue el modo del perfil activo. Nuevos en el catálogo: `bubblewrap` (backend de terminal bwrap en Linux), Singularity/Apptainer, `mcp-serve` (Hermes como servidor MCP), `agent-importers` (`hermes import-agent`, ahora con Cursor), `inbox` y `workflow-record`.

Medido en `bf0203a794a`: 231 commits no-merge, 804 archivos (+35.212 / −17.885), 81 PRs, 30 issues cerrados.

- **Nous sign-in reworkeado**: todo inicio de sesión es el device login simple; el invitado de free-tier cede a la cuenta; el resultado muestra quién inició sesión; los conectores ofrecen iniciar sesión en vez de abrir un invitado.

## Nota operativa para este servidor

La delegación de subagentes se configura con `hermes config set delegation.model` / `delegation.provider`. Si el ID no existe en el proveedor, cada `delegate_task` muere en menos de un segundo con HTTP 400 y, en una sesión de cron sin terminal, no queda camino para ejecutar prettier/git. Con los backends conectables de 0.22.5 el enrutado puede cambiarse por sesión sin editar el archivo de configuración a mano desde una tool (que rechaza escribir en `~/.hermes/config.yaml`).
