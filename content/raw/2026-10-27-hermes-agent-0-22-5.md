## Hermes Agent v0.22.5

**Release Date:** October 22, 2026

> Patch release. This tag rolls up the ~81 PRs merged since v0.22.4 into a stable release for the GitHub release (CLI and installers), the Microsoft Store app, Docker and Hermes Cloud. Full curated notes for this window ship with v0.23.0.

### About this release

Measured at commit `bf0203a794a`, the window since v0.22.4 contains **231 non-merge commits** across **804 changed files** (+35,212 / −17,885), **81 merged PRs** and **30 closed issues**.

Also in the window, undocumented here on purpose:

- Nous sign-in reworked (every sign-in is the plain device login, the free-tier guest hands over to your account, the result shows who signed in, connectors offer sign-in instead of opening a guest).
- `hermes update` holding back a stable release it refuses instead of offering it.
- Windows `hermes update` no longer stuck on the old launcher after a Python repin.
- Usage-window plan support (plan gauges, limit cards and model-switch recovery for window-based plans).
- **Pluggable delegation backends** (route subagents by model map or profile, switchable per session).
- Plugin slash commands that can ask you to pick an option.
- `hermes import-agent`, OpenClaw migration.
- **`hermes mcp serve` and the Singularity backend moving out of core into plugins** (setup offers the importer when it finds another agent).
- Desktop drag-to-pin in the sidebar and one-click plugin installs with tier badges.
- The Electron 44 upgrade, Pillow 13 and a batch of dependency security bumps.
- A clear message when a chat's working folder is gone.
- `hermes update` recovering paused gateways after a damaged `.git`.
- Long Claude DirectSDK answers no longer cut off by the stall timer.
- Desktop group chats showing which bot is working again.
- The experimental webhook-mode MCP events client.

**Full curated release notes for this window ship with v0.23.0**, which will document everything from v0.22.0 onward — highlights, feature areas, and complete contributor credits. Nothing in this window is skipped.

### Updating

- Microsoft Store app: updates through the Store.
- Desktop app installed from the installer (.exe / .dmg): no change in this release; it updates with the next bundled release.
- CLI: `hermes update`, or re-run the installer one-liner.
- Docker / Hermes Cloud: `nousresearch/hermes-agent:stable` (or `:latest`).

## Hermes Agent v0.22.4 (21 de octubre de 2026)

> Patch release. Desktop stops showing suggestion pills above the composer, plus small plugin and dashboard fixes, for the CLI and installer, the Microsoft Store app, Docker and Hermes Cloud.

Fixes:

- Desktop no longer shows suggestion pills above the composer (#142559).
- Plugins that install nothing skip the dependency consent step (#142569).
- Dashboard: WhatsApp can be safely re-paired after logging out (#142439).
- Desktop plugin review: the surface lint no longer flags prototype writes (#142586).
- Desktop: the approval-mode chip follows the active profile's mode (#142565).
- Release builds: the desktop bundle's pre-build check gets enough time to verify archived build inputs when storage is slow (#142623).

Also new in the plugin catalog: bubblewrap (bwrap terminal backend on Linux), Singularity/Apptainer, mcp-serve (Hermes as an MCP server), agent-importers (`hermes import-agent`, now with Cursor), inbox and workflow-record from Hermes Labs. Telegram Business moves to the Hermes Labs community tier.

Measured at commit `4d04303818b`, the window since v0.22.3 contains **14 non-merge commits** across **82 changed files** (+1,475 / −3,022) and **13 merged PRs**.

## Hermes Agent v0.22.3 (21 de octubre de 2026)

> Patch release. This tag rolls up the ~620 PRs merged since v0.22.2 into a stable release.

Measured at commit `5b147ab036d`, the window since v0.22.2 contains **2,911 non-merge commits** across **4,206 changed files** (+360,278 / −64,308), about **620 merged PRs** and **326 closed issues**.

Also in the window, undocumented here on purpose: MCP progress notifications streamed as live tool progress, a refreshed classic CLI layout (glyph transcript, status line under the composer, two-line header), OAuth clients that plugins declare and Hermes signs in and refreshes, `hermes plugins update` offering every available plugin update plus an Update button for git-installed plugins in Desktop, steering and editing a queued prompt from Desktop, a guided subagent model and provider picker in Desktop, a live `/loop` countdown row in the CLI and TUI, opt-in Telegram DM topic transfer, a `post_compaction` plugin hook, a capabilities catalog, the Microsoft Store build going live automatically when a release publishes, session auto-prune back to opt-in with a one-time prompt when disk runs low, Nemotron 3.5 Bolt and one-slot DFlash drafts in the local runtime, and dozens of new plugin catalog entries.
