# Thrum releases multi-agent coordination platform for Claude Code, Codex, and Cursor

Builders, 10 noviembre 2026 — The Agent Brief (Get Ready for Agents by Prefactor).

According to Thrum's announcement, the platform enables agents running on different tools to message each other and coordinate work without manual data transfer. Thrum offers a free tier requiring no account and a paid Pro plan at $15/month or $120/year that adds web UI messaging and agent memory features. The service supports coordinator-reviewer workflows with approval loops and runs on Claude Code, Codex, and Cursor.
