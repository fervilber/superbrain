# Hermes Agent v0.22.7

Agent Updates (feed de changelog de Hermes Agent, Nous Research) — 3 de noviembre de 2026. Captura verbatim de las notas retenidas. Extraído vía `web_extract`.

## Nov 03 2026 — Hermes Agent v0.22.7

1. About this release: Also in the window, undocumented here on purpose: opt-in lead routing for Desktop Group Chats (with a Lead badge on the room header), cron jobs that post into Group Chats, room purpose and shared notes, group rooms laid out in one chat column with each member's live state, pinned Kanban boards as quick-switch tabs, `$$TeX$$` diagram labels and mermaid diagrams rendered through Pele, a Desktop update error box that shows the failed update's output with a report link, Web Access naming the step Start is on with a running clock, Telegram on Team Gateway set up by linking an account to the shared bot, an opt-in Slack thread-follow-up-silence for unaddressed thread replies, a Daybreak switch for catalog-listed ChatGPT subscription models, and a batch of new plugin-catalog entries.

解读 (resumen del changelog en chino, verbatim): 这一版集中上线了一批团队协作与可视化相关的新能力，值得关注的有：桌面端群聊支持"负责人路由"（房间顶部会显示 Lead 徽章），让群里的事务能明确指派给某个人；定时任务（cron）现在可以直接把结果发进群聊房间，比如设置一个每天早上 9 点把构建结果或日报推送进"研发群"，不用再手动转发；房间可以填写用途说明和共享笔记，成员进入房间就能看到上下文；多个群组房间被收拢在同一个聊天栏里，并实时显示每个成员当前状态；看板可以固定为顶部快捷标签页，一键切换。显示方面，`$$TeX$$` 公式标签和 mermaid 流程图可以直接渲染出来（例如在文档里写一段 mermaid 流程描述就能看到图形），桌面端更新失败时会弹出错误框，显示失败更新的输出并附上报告链接，方便排查；Web Access 会显示当前进行到哪一步并带运行计时；Telegram 在 Team Gateway 下通过"把账号绑定到共享机器人"来完成配置；Slack 新增可选的线程跟进静默，避免未被回应的线程反复提醒；还增加了 Daybreak 开关用于目录中列出的 ChatGPT 订阅模型，并补充了一批插件目录条目。整体上，这些改动让多人协作、任务自动化分发和信息可视化都更顺手。

## Nov 02 2026 — Hermes Agent v0.22.6 (contexto)

About this release: the Webapp served from the gateway's own listener (`hermes webapp`, a Desktop Web Access pane to open it on your network or your own URL behind Nous sign-in, and Desktop plugins loading in a browser tab), `/model reset` to clear a session's model pin without losing history, per-skill locks against autonomous writes (lockable from the Desktop Capabilities pane), opt-in prepared compaction (`compression.prepare_ahead`), `hermes cron cancel` plus a per-job missed-run policy and a Stop button in the Desktop cron editor, `/delegation` choices saved for the next session, `hermes migrate` and setup moving Grok Bot and OpenBot users over, opt-in OS-keychain storage for the vault key, the catalog's `requires_hermes` enforced at plugin install and update, agent-picked ElevenLabs voices in text-to-speech, a pre-LLM-call hook that can block a turn before inference, Desktop group chat rename, disband, mentions and attachment paste, every profile shown as a Desktop sidebar section, Telegram video notes, Slack emoji reactions in thread context, and resumable downloads in the package manager.
