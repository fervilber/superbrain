# Hermes Agent v0.23.1

Release Date: November 9, 2026. Publicado por teknium1 (tag inmutable).

> Patch release. This tag rolls up the ~618 PRs merged since v0.23.0 into a stable release for the GitHub release (CLI and installers), the Microsoft Store app, Docker and Hermes Cloud. Full curated notes for this window ship with v0.24.0.

## Qué arregla para usuarios de plugins

Since the plugin catalog's site deploy on November 9, the published `plugin-catalog.json` was larger than the 2 MiB cap clients accept, so every install silently fell back to the catalog it shipped with. `hermes plugins install` could not find plugins added since your last update, installed the pin your release shipped instead of the current one, and missed newer `removed` entries. This release raises the cap to 16 MiB, so the live catalog is used again (#151860, fixes #151856, thanks @100yenadmin). Installs that stay on v0.23.0 or older keep falling back until they update.

## About this release

Measured at commit `3b421578588`, the window since v0.23.0 contains 2,578 non-merge commits across 2,781 changed files (+151,690 / −62,595), 618 merged PRs and 409 closed issues.

Also in the window, undocumented here on purpose:

- Esc backtrack in the TUI and classic CLI (replacing the rewind list picker)
- group chats that run on a gateway without Desktop and can seat bots from other computers
- saved gateway connections shared by Desktop and the Webapp
- signing the in-app browser in with your real browser profile and filling saved logins from its address bar
- `hermes gateway attach` for local clients
- `hermes clipboard image --json`
- new plugin API (session-scoped environment values, plugin JSON-RPC methods and events, `llm.oneshot` auxiliary tasks, a compression-stable `conversation_id`, an `on_session_open` hook in the gateway, a `post_curator_run` hook)
- faster transcript and handoff reads
- a large batch of new plugin-catalog entries

Full curated release notes for this window ship with v0.24.0, which will document everything from v0.23.0 onward.

## Updating

- Microsoft Store app: updates through the Store.
- Desktop app installed from the installer (.exe / .dmg): no change in this release.
- CLI: `hermes update`, or re-run the installer one-liner.
- Docker / Hermes Cloud: `nousresearch/hermes-agent:stable` (or `:latest`).

## Contexto: v0.23.0 — The Hearth Release (5 nov 2026)

Since v0.22.0: ~10,080 commits · ~1,950 merged PRs · ~8,720 files changed · ~725,200 insertions · ~201,400 deletions · ~850 issues closed · 666 contributors. El titular: todo el espacio de trabajo de Desktop se abre ahora en una pestaña del navegador servida por tu propio gateway. Debajo, cada conversación vive en un solo lugar: un único gateway posee cada sesión, y el CLI, TUI, Desktop, editores, bots y cron se sientan a la misma mesa en lugar de ejecutar cada uno su propio agente. Además: plugins que se autoactualizan, etiquetas de precio y límites de gasto en herramientas MCP de pago, delegación enchufable, un catálogo de plugins que creció de ~600 a más de 1.050 entradas, un conjunto de skills integradas más ligero y trabajo de memoria y latencia para gateways de larga vida.
